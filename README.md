# text-to-image

## Scope

Generate images locally on Apple Silicon using MLX-native models. Supports FLUX.2 Klein and Qwen-Image for prompt-based generation and editing without cloud APIs.

TRIGGERS: Use when:
- User asks to generate an image from text locally
- User wants local image generation or editing on Apple Silicon
- User mentions FLUX, Qwen-Image, mflux, or MLX image generation
- User wants images without sending prompts to a cloud image API

- Skill trigger: Generate images locally.
